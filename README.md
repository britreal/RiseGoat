# Notas

Aplicativo pessoal de notas, construído com React + TypeScript + Vite + Supabase.

## Produto
O site agora é o Notas. A antiga experiência de blog, newsletter, vendas e módulos de negócio não faz mais parte da interface do produto.

- `/` — landing page
- `/auth` — acesso
- `/notes` — aplicativo

O histórico de migrations antigas do Supabase é mantido apenas como histórico técnico; removê-las do repositório não desfaz alterações já aplicadas no banco.
